El login es el proceso mediante el cual una persona ingresa a una aplicación utilizando sus credenciales para verificar su identidad. Esto permite que cada usuario acceda únicamente a las funciones que le corresponden. Algunas rutas deben estar protegidas porque pueden contener información privada o permitir acciones importantes dentro de la plataforma. De esta manera, se evita el acceso no autorizado y se protege la información de la comunidad. No se deben exponer públicamente contraseñas, documentos de identidad, teléfonos, direcciones, tokens, claves de API ni otros datos sensibles. Así se garantiza una mayor privacidad y seguridad para todos los usuarios.
